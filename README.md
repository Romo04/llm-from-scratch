# llm-from-scratch

Code along of *Build a Large Language Model (From Scratch)* by Sebastian Raschka's with my own shenanigangs.

## Prerequisites
- Python 3.12+ (That's what i used at least)

## Setup (why would you tho)
```bash
git clone https://github.com/Romo04/llm-from-scratch
cd llm-from-scratch

python3 -m venv .venv
source .venv/bin/activate

pip install -r https://raw.githubusercontent.com/rasbt/LLMs-from-scratch/main/requirements.txt  
```
